FEA & Machine Learning-Based Optimization of an Automotive Lower Control Arm

Structural analysis and data-driven optimization of a lower control arm by investigating the influence of component thickness and fillet radius on mechanical performance.

DOMAIN Structural FEA
LOAD 3.7 kN
CONFIGURATIONS 30 Designs
APPROACH FEA + ML
SOLIDWORKS ANSYS FEA PYTHON MACHINE LEARNING
STRUCTURAL / FEA
ILLUSTRATIVE MODEL
01 / PROJECT OVERVIEW

Optimizing a Critical Suspension Component

The lower control arm is a critical suspension component responsible for connecting the wheel assembly to the vehicle chassis while transmitting suspension loads.

This project focuses on analyzing and optimizing a lower control arm using Finite Element Analysis (FEA) and Machine Learning (ML).

The influence of structural thickness and fillet radius on the mechanical performance of the component is investigated under a representative wheel load.

04 / FEA ANALYSIS

Structural Response

FEA is used to evaluate the structural response of the lower control arm under the applied representative wheel load.

PERFORMANCE PARAMETERS

Structural Metrics

Maximum von-Mises Stress

Primary stress metric used to evaluate structural response.

Total Deformation

Measures the structural displacement under applied loading.

Factor of Safety

Used as a structural safety performance indicator.

Component Mass

Included when considering the strength-weight trade-off.

05 / MACHINE LEARNING

Turning FEA Data into Predictive Models

Machine Learning models are developed using the FEA dataset to establish relationships between geometric parameters and structural performance.

The trained regression models are then used to predict structural performance and identify promising design configurations.

MODEL 01

Linear Regression

Baseline regression model for establishing parameter relationships.

MODEL 02

Decision Tree Regression

Non-linear regression approach for design-performance relationships.

MODEL 03

Random Forest Regression

Ensemble-based regression model for predictive structural analysis.

MODEL INPUTS

01 Component thickness

03 Applied wheel load
MODEL OUTPUTS
