Numerical Analysis of Single Cylinder Diesel Engine using ANSYS Forte

Project Type: Academic CFD Project

Project Overview

This project focuses on the numerical simulation and combustion analysis of a single-cylinder diesel engine using ANSYS Forte. The objective was to investigate combustion characteristics, in-cylinder pressure development and heat release behaviour through Computational Fluid Dynamics (CFD) techniques.

The simulation results were validated with experimental engine data to evaluate the accuracy of the numerical model and gain deeper insights into diesel combustion processes.

Objectives

  • Develop a CFD model of a single-cylinder diesel engine.
  • Simulate fuel injection and combustion processes.
  • Analyze in-cylinder pressure and temperature variation.
  • Study chemical heat release characteristics.
  • Validate simulation results using experimental data.
  • Understand diesel combustion behaviour using numerical methods.

Methodology

The engine geometry and operating conditions were defined in ANSYS Forte. Appropriate spray, turbulence and combustion models were selected to simulate diesel fuel injection and combustion. The simulation was performed over the engine cycle and the obtained results were post-processed for analysis and validation.

Software Used

  • ANSYS Forte
  • ANSYS CFD Post
  • MATLAB
  • Microsoft Excel

Parameters Investigated

  • In-Cylinder Pressure
  • Temperature Distribution
  • Chemical Heat Release Rate
  • Combustion Characteristics
  • Simulation Accuracy

Results & Validation

  • Maximum simulated in-cylinder pressure: 67 bar
  • Experimental peak pressure: 65 bar
  • Simulation deviation: 3.08%
  • Peak in-cylinder temperature: 1250 K
  • Maximum chemical heat release rate: 70 J/degree CA

Key Achievement

Successfully developed and validated an ANSYS Forte combustion model for a single-cylinder diesel engine, achieving only 3.08% deviation between simulated and experimental peak cylinder pressure.
