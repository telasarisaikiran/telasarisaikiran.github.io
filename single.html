Numerical Analysis of Single Cylinder Diesel Engine using ANSYS Forte

A numerical combustion study of a single-cylinder diesel engine using ANSYS Forte, developed in connection with experimental low-temperature combustion work and validated against measured in-cylinder pressure data.

ILLUSTRATIVE ENGINE COMBUSTION SCHEMATIC · NOT A SIMULATION RESULT
01 / AT A GLANCE
SOFTWARE ANSYS Forte
ENGINE Single Cylinder Diesel
SIMULATED PEAK 67 bar
EXPERIMENTAL PEAK 65 bar
02 / PROJECT OVERVIEW

This project investigated the combustion behaviour of a single-cylinder diesel engine through numerical simulation using ANSYS Forte.

The work was connected to experimental studies on low-temperature combustion strategies. The numerical model was used to examine important in-cylinder quantities including pressure, temperature, heat release behaviour, fuel distribution and combustion characteristics.

Experimental cylinder-pressure data were used as a reference for evaluating the numerical model.

06 / METHODOLOGY
  1. 01
    Engine geometry definition

    Defined bore, stroke, combustion-chamber geometry and relevant engine dimensions.

  2. 02
    Sector model generation

    Constructed the 60° sector representation for computational analysis.

  3. 03
    Mesh generation

    Established mesh topology, control points and mesh sizing for the moving engine domain.

  4. 04
    Physical model setup

    Configured turbulence, spray, combustion, chemical kinetics and heat-transfer models.

  5. 05
    Numerical simulation

    Simulated the engine combustion process over the selected crank-angle range.

  6. 06
    Post-processing & validation

    Evaluated in-cylinder quantities and compared simulated pressure with experimental data.

09 / ENGINEERING INSIGHTS
  • Numerical combustion modelling provides access to spatial and temporal quantities that are difficult to obtain from engine experiments alone.
  • Sector modelling can reduce computational expense when geometric and injection symmetry permit its use.
  • Turbulence, spray breakup, chemical kinetics and heat transfer interact strongly during diesel combustion.
  • Experimental pressure data provide an important reference for assessing numerical predictions.
  • The simulated and experimental peak-pressure values showed close agreement for the investigated case.

11 / KEY TAKEAWAY
PROJECT OUTCOME

Simulation connected with experiment.

The project established a numerical ANSYS Forte workflow for analysing single-cylinder diesel combustion and comparing predicted cylinder pressure against experimental measurements.

Peak simulated pressure was 67 bar, compared with 65 bar experimentally, corresponding to approximately 3.1% deviation.
