PROJECT OVERVIEW

Why Battery Thermal Management?

Lithium-ion batteries generate heat during charging and discharging. Controlling this heat is important for maintaining battery safety, performance and service life.

This project focuses on developing a computational Battery Thermal Management System (BTMS) framework using Computational Fluid Dynamics and Machine Learning.

CFD simulations are used to investigate the thermal and flow behaviour of the battery module under different operating conditions. The resulting simulation data can then be used as a basis for predictive modelling.

MACHINE LEARNING

From CFD Data to Predictive Models

High-fidelity CFD simulations provide detailed information about the thermal response of the battery module.

The proposed framework uses simulation datasets to investigate Machine Learning models capable of predicting cooling requirements for different battery operating conditions.

The long-term objective is to reduce the dependence on repeated computationally expensive simulations when evaluating different operating conditions.
